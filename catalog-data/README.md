# Данные каталога KIDRIVE

`cars.json` содержит подготовленные данные 30 карточек. `update-catalog.sql` — запрос, применённый к локальной базе: он обновляет записи 1–21 и добавляет записи 22–30. Повторно запускать его без проверки базы нельзя: идентификаторы добавленных записей уже заняты.

Изображения созданы встроенным инструментом генерации изображений для каждой модели по отдельности. Общий запрос: «Фотореалистичное изображение автомобиля для каталога: один автомобиль указанной марки, модели и года; передний ракурс три четверти, автомобиль и колёса целиком в кадре с запасом; нейтральный светло-серый студийный фон, нейтральное освещение, горизонтальный формат, без надписей, водяных знаков и других автомобилей». Названия моделей и годы находятся в `cars.json`.

Изображения являются иллюстрациями, а описания, характеристики и цены новых записей — примерными данными каталога. Перед использованием для реальных автомобилей следует сверить год, комплектацию, мощность и стоимость с фактическими данными.
